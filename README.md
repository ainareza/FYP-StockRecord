# StockRecord Inventory Management System

## About the Project
This project is a web-based Inventory Management System developed as part of a Final Year Project (FYP). It aims to facilitate inventory management by 
organising inventory records and supporting related management processes. This project does not provide a public sign-up. User account(s) must be created and
managed by the Store Owner as Admin.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP

## Installation and Setup
1. Install a local server environment that supports PHP and MySQL.
2. Clone or download this repository.
3. Place the project folder in your server's web directory.
4. Create a MySQL database for the system.
5. Import the provided database schema or SQL file, if available.
6. Configure the database connection using your local credentials.
7. Start the web server and MySQL service.
8. Open the project through your local server in a web browser.

## Database Configuration
Configure the database connection using your local settings. Do not commit passwords or other sensitive credentials to this repository.

## Project Status
Developed for academic purposes as a Final Year Project.

## Creating the Initial Store Owner Account
1. Set up the MySQL database and import the required database structure.
2. Create the initial Store Owner account using the appropriate database setup procedure.
3. Ensure the account's password is securely hashed, and its role is assigned correctly.
4. Sign in through the StockRecord login page.
5. Signing In
6. Open StockRecord in your web browser.
7. Enter your registered email address and password.
8. Click Sign In to access the system.

Note: Accounts that have been deactivated cannot sign in. Contact the Store Owner for account assistance.
